HOW IT WORKS

学习方法

拾词不追求一次记住。它只做一件事：在你快要忘记的时候，安排一次诚实的重逢。

SLOW · STEADY

少量，专注，重复。
然后交给时间。

每天 12 个词，大约 10 分钟。先在心里回答，再翻面核对；答对两次，才算真正掌握。剩下的，交给第二天的复习和一次小小的挑战。

01

先回忆，再翻面

看到单词时，先逼自己说出意思。哪怕想错，也比直接看答案更有用——回忆本身就是在加固记忆。

02

答对两次，才算掌握

一次答对可能只是短期熟悉。拾词要求连续两次答对，才把词收进「已掌握」，避免虚假的进度感。

03

每天只要 12 个

目标小到不容易放弃。完成之后想继续，当然可以；但今天的基础任务，到这里就够了。

A WEEK WITH SHICI

一周怎么用

  1. 周一到周五 · 每天一组打开「今日学习」，完成 12 个词。不追求速度，只要求每个词都先回忆过。
  2. 周末 · 去词库看看按「待复习」筛选，把还不熟的词再翻一遍；点开卡片可以标记掌握，也可以朗读。
  3. 任意一天 · 做一次挑战10 道随机题，检查记忆是不是真的迁移到了新的选项里。错题会自动回到薄弱词列表。
  4. 每月 · 看一次统计不比较排名，只看连续天数、掌握数量和词库分布，决定下个月要不要换一个场景词包。

ABOUT THIS PROJECT

关于这个项目

拾词是一个课程项目，也是一个真正被使用的单词工具。它用原生 HTML、CSS 和 JavaScript 写成，不依赖框架，也不依赖后端：所有学习记录只留在当前浏览器。

界面围绕「安静地学一会儿」设计：低饱和的纸张色、衬线大字、克制的动效。代码与提交记录都放在 GitHub 上，从第一版到现在的每一次改动都可以追溯。

查看 GitHub 仓库 ↗

数据与边界

  • 240 个词，12 个场景词包，全部内置在 data.js。
  • 进度保存在 localStorage，换浏览器或清缓存会重新开始。
  • 没有账号、没有服务器，也没有把你的学习记录发给任何人。
  • 语音朗读使用浏览器自带的语音合成，支持情况取决于设备。
