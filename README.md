# 拾词 · SHICI

一个安静、专注的背单词网站。纯 HTML / CSS / JavaScript 实现，没有构建步骤，也没有后端。

## 五个页面

| 页面 | 地址 | 内容 |
| --- | --- | --- |
| 今日学习 | `index.html` | 每日 12 词、翻面回忆、连续学习与今日目标 |
| 我的词库 | `library.html` | 240 词搜索与筛选、12 个场景词包、词条详情 |
| 词义挑战 | `quiz.html` | 随机 10 题四选一、即时解析、最佳成绩 |
| 学习统计 | `stats.html` | 7 天记录、掌握进度、分类与主题足迹、薄弱词 |
| 学习方法 | `about.html` | 学习原则、一周使用方式、数据边界与项目说明 |

`404.html` 提供站内兜底；主导航在桌面端是左侧栏，在窄屏上变成五栏底部导航。

## 运行

直接双击 `index.html` 即可浏览。若希望字体、朗读和本地存储表现更稳定，也可以在当前目录启动一个静态服务器：

```powershell
python -m http.server 4173
```

然后访问 <http://127.0.0.1:4173>。

## 功能

- **今日学习**：12 词一组，先回忆再翻面；支持 `Space` 显示释义、`1` 不认识、`2` 认识。答对两次才计入「已掌握」。
- **240 词词库**：核心高频、学术进阶、商务职场、生活表达四类；支持搜索、学习状态、分类与主题筛选。
- **12 个场景词包**：旅行出行、饮食日常、职场沟通、媒体观点、情绪心理、教育学习、社交关系、居家生活、环境自然、健康医疗、科技网络、购物消费。每个词包 20 词，点开即可开始一组主题学习。
- **词库分批加载**：默认展示 30 个，继续加载下一批，避免一次渲染全部卡片。
- **搭配与易混**：翻面和词条详情中展示常用搭配；部分易混词附带辨析提示。
- **词义挑战**：随机 10 题四选一，即时解析，记录最佳成绩；支持 `1`–`4` 选择、`Enter` 继续。
- **学习统计**：连续学习、7 天柱状图、掌握进度、分类进度、12 个主题足迹与薄弱词复习。
- **本地保存**：学习记录写入浏览器 `localStorage`，不会上传到服务器。
- **响应式**：桌面侧边栏与移动端底部导航两套布局。
- **语义与可访问性**：每页一个 `h1`、跳转到主内容链接、可见焦点、`aria-current` 导航状态、键盘可完成学习与答题。
- **语音朗读**：调用浏览器自带的 Web Speech API。
